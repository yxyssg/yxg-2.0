# 前言

## 这本书是什么？

这是一本 YXG 编程语言的完整教程。YXG 是一门静态类型、编译到原生代码的语言，语法接近 C，同时支持面向对象、泛型、异常处理和模块系统。

本书从零开始讲起：先跑通第一个程序，再系统梳理语言的每一处细节，然后用六个完整项目把知识串起来，最后附上标准库 API 和错误码速查。第三部分还会带你走进编译器内部，看看源码是怎么一步步变成汇编的。

## 适合谁读？

- 对编程语言设计与实现感兴趣的开发者
- 讲编译原理、需要现成教学案例的教师和学生

## 你需要什么基础？

- 了解基本编程概念（变量、循环、函数、类）
- 熟悉 C 语言或 Java 会更轻松，但不是必须
- 第三部分涉及汇编和编译器理论，需要一点预处理知识

## 关于 YXG 语言

YXG 的设计目标是**简单而不简陋**。语言核心保持在可手写的规模内，同时提供了实际开发需要的东西：

| 特性 | 说明 |
|---|---|
| 静态类型 | 8 种常用类型 + 窄/宽变体（`int8`~`int64`、`float64`）+ 类 + 泛型 |
| 面向对象 | 类、继承、访问控制、虚函数派发 |
| 泛型 | 泛型类、泛型函数、嵌套泛型 |
| 异常处理 | `try` / `catch` / `end` |
| 模块系统 | `import yxg.xxx` 点路径导入 |
| 函数对象 | 函数可以当值传递 |
| 指针 | `&` / `*`、多级指针、指针运算、类指针 |
| 函数指针 | 作参数、作返回值、数组、嵌套、多返回值 |
| 多返回值 | `(int, string)` + `getReturn(i)`，支持可变返回值 |
| 可变参数 | `f([1,2,3])`，支持多个变参组 |

编译器完全用 C 手写，不依赖 Yacc/Lex/LLVM，流水线是：

```
词法分析 → 语法分析 → 语义分析 → 三地址码 IR
→ 控制流图 → SSA → 优化 → 寄存器分配 → NASM 汇编
```

产物是 Windows x86 原生可执行文件，启动快、无虚拟机。

## 本书结构

全书分五个部分加附录：

**第一部分：快速入门。** 搭环境、编译第一个程序、看懂命令行参数、编写 `yxg.toml`，再给一份语言全景速览。

**第二部分：YXG 语言参考。** 逐个讲清楚每一处语法和语义：

| 主题 | 内容 |
|---|---|
| 基础 | 类型、变量、运算符、控制流 |
| 函数 | 定义、参数、返回值、重载、递归 |
| 指针 | `&` / `*`、多级、运算、类指针、函数指针 |
| 多返回值 | `(int, string)`、可变返回值、可变参数 |
| 数据 | 数组、字符串 |
| 面向对象 | 类、继承、访问控制 |
| 进阶 | 枚举、异常、泛型、函数对象、模块 |
| 库 | 内置函数、标准库 |

每个要点都配可运行的例子。

**第三部分：编译器架构概览。** 从源码到汇编的完整流水线、核心数据结构、错误诊断系统。读完能看懂编译器源码在干什么。

**第四部分：实战教程。** 六个完整项目，每个都实跑验证过输出：

| 项目 | 练什么 |
|---|---|
| 成绩统计 | 数组遍历、多变量累积、下标当分类键 |
| 文本分析工具 | 字符串扫描、ASCII 码操作、状态标记 |
| 库存管理 | 类、构造、数组存对象、`virtual`/`override` |
| JSON 数据处理 | `JsonValue` 全套 API、嵌套结构、类型判断 |
| 配置读写 | 自定义异常、多 `catch`、`end` 收尾、文件读写 |
| 数据聚合 | `List<T>`、`Map<K,V>`、泛型容器 |

**第五部分：图形与多媒体库。** Window 窗口、Canvas 画布、16 个 GUI 控件、音频、视频，以及 Socket 网络和文件库。

**附录。** 编译错误码速查（含实测报错文本）、术语表、参考资料。

| 完全新手 | 按顺序读，每个例子都亲手敲一遍、跑一遍 |

| 查 API | 直接翻[标准库](part2/stdlib.md)和[图形与多媒体库](part5/graphics.md) |

## 一个约定

本书所有示例都在 YXG 2.0 上实际编译运行过，输出与文中一致。如果你跑出来的结果不同，先检查两件事：

1. 编译器版本是不是 2.0
2. `runtime_cache/` 里是不是残留了旧的目标文件
